# 🌵 Painel de Análise de Dados — Sabor do Sertão

Projeto desenvolvido como atividade prática de análise de dados utilizando Python, Pandas, Streamlit e Plotly.

O projeto apresenta um painel interativo para análise das vendas da rede fictícia de lanchonetes **Sabor do Sertão**, permitindo visualizar indicadores, gráficos e insights gerenciais.

---

## 📊 Funcionalidades

O painel possui:

- 🔎 Filtros por cidade
- 🍔 Filtros por categoria
- 📅 Filtro por período
- 💰 Faturamento total
- 🧾 Número de vendas
- 🎟️ Ticket médio
- ⭐ Avaliação média
- 📈 Faturamento mensal
- 🏙️ Faturamento por cidade
- 🏆 Top 5 produtos
- 💳 Distribuição das formas de pagamento
- 💡 Insights gerenciais
- 📥 Exportação dos dados filtrados em CSV

---

## 🛠️ Tecnologias utilizadas

- Python 3
- Pandas
- Streamlit
- Plotly
- NumPy
